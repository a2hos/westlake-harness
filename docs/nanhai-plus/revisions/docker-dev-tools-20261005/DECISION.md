# Docker 使用边界修订

日期：2026-10-05

用户最新决定：Docker/Podman/OCI 可以作为开发过程中的辅助工具，但不能成为系统架构或项目交付的一部分。

允许：静态扫描、依赖准备、测试夹具、可复现实验、失败定位。每次必须记录镜像、命令、输入、输出和用途，并标注 `dev-only`。

禁止计入交付：App 运行时、OH 服务运行时、正式系统镜像、正式 Bionic 目标产物、安装/冷启动/上屏、设备验收，以及任何声称单一 Bionic 架构已完成的证据。正式构图和目标编译优先使用可审计原生宿主路径；开发容器结果不能直接升级为交付 PASS。

历史无容器修订和 G252-G277 收据继续保留为审计材料；本修订不恢复任何旧封包、旧 nonce 或旧设备授权。
