# EVO52：判定值必须有可复核见证

四组结果显示同一边界：v5 代码审查 GO，但真实 rc255 的 `PRE_BANNER_CLOSED_LINE_SEEN` 只由运行器自报；原始 1462 字节 SSH 错误流已删，事后独审只能保留“运行器报告见过该行”，不能复核行本身或证明远端 TCP。AlexPC v1 则把远端四个布尔值当成本地通过条件，矛盾事实负例仍被接受，独审 NO_GO。

只提出一项改进：凡改变门禁的结果，保存经固定 schema 白名单收缩的最小安全见证，并让独立本地验证器从见证重算；若无法安全保留，就明确 `UNKNOWN_UNREPLAYABLE`。本地小试对真实 v5 旧收据维持 UNKNOWN；模拟完整固定 SSH 行可复算，带敏感后缀或前缀被拒，AlexPC v1 自报布尔值不足以通过。小试没有连接或设备操作，尚不推广。

下一次仅选择一个真实候选验证“安全见证→独立重算→同一判定”；若见证包含私有节点或凭据，立即停止该方式并保持 UNKNOWN。
