# G279 v2c v4 — diagnostic bounds and stage ordering, code only

The frozen v3 peer `NO_GO_V2C_V3_CODE_ONLY_DIAGNOSTIC_VALIDATOR` (`3d578c14…`) found two accepted false receipts: an impossible SSH child rc with unbounded byte counts, and a positive route claim at instance stage `NONE`. v4 is a new candidate directory. v2's consumed nonce and v3's rejected code are not replayed. No v4 peer GO, root release, START or TERMINAL exists.

`replay_ssh_diagnostic` now permits a child rc only in macOS signal/exit range `-31..255`; null is allowed only for timeout. Published stdout and stderr counts are limited to 65,536 and 1,048,576 bytes. It rejects a numeric-UID observation with nonzero rc, a proof-verified category without the UID stage, a line stage with zero stderr, and category/stage mismatches for host key, authentication and UID. Oversized captured output fails the diagnostic gate; the current `communicate` call is time bounded but does not proactively cap in-memory capture, so this is a publication bound rather than a streaming-memory guarantee.

`validate_instance_diagnostic` now enforces a monotonic sequence: local REJECT requires its witness stage; SSH outcome requires the local SSH-launch stage; SSH identity and later stages require a verified SSH proof; positive route requires local REJECT plus completed post-SSH guards and the route-witness stage. It rejects a success stage with a failure category and mismatched SSH/route failure categories. Fixed enum fields carry no raw SSH stream, arbitrary exception text, real node label or credential.

The fixture suite includes both exact v3 peer counterexamples, neighboring lower/upper rc and byte bounds, null/timeout, rc/UID, stage/category, route ordering, and valid edge cases. It uses only fake SSH outputs, prior no-credential loopback format evidence and local `ssh -G` expansion. It does not make any new real connection or run selected-node Mihomo. The v2 failed substage remains `UNKNOWN`; v4 diagnostics cannot retroactively determine it. An independent v4 code review is required before any one-shot release.
