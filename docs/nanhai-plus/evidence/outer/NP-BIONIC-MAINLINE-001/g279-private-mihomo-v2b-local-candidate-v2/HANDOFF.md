# G279 v2b v2: exact-binary local REJECT oracle, code candidate

v1 remains NO_GO at its frozen path and peer receipt. v2 uses a new candidate directory and one-shot release schema. No v2 root release, START, or TERMINAL exists; the real selected node was not started.

The v1 defect was material: accepting two SOCKS reply bytes or any nonzero REP could call a malformed/generic failure a rule rejection. The bundled Mihomo actually returns a complete SOCKS5 `REP=0` before closing the connection for `MATCH,REJECT`. The v2 parser reads and checks the full version, reserved byte, address type, address, and port. A TEST-NET-3 request must then close without data. This stream behavior alone is recorded only as connection closure. The `MATCH,REJECT` selection requires exactly one private debug log event for `203.0.113.1:9 match Match using REJECT`; a generic word REJECT, a different target/action, or duplicate event fails. The raw real-node debug log remains 0600 inside the private runtime and is deleted after verified process stop; only its hash/size and exact route-event hash can leave in TERMINAL.

The exact bundled Mihomo was run once with a credential-free private mock config (`MOCK-CONFIG.yaml`), the same two rules and debug log level, a fake SOCKS node pointing only to `127.0.0.1:9`, and a loopback listener. `MOCK-ORACLE.json` binds the binary/config/policy hashes and records complete reply, EOF, exact route-event SHA, process cleanup, and no gz02 request. `MOCK-STDOUT.raw` preserves the actual route line; `MOCK-STDERR.raw` is empty. The mock process ended and its private runtime was removed. This validates the local negative oracle, not the real node, gz02 `/32` PROXY route, SSH, graph, App startup, or device behavior.

No-credential fixtures cover complete reply shape, truncation, generic REP=5, fake success with data, malformed ATYP, broadened `/32`, `MATCH,DIRECT`, generic/different/duplicate route log, and kernel `lsof -Fpcfn` PID and loopback address readback. They used only a temporary Python loopback server and fake SOCKS server, plus the saved mock log. `FIXTURE.json` records results.

Peer review must bind every frozen SHA and inspect credential/log cleanup, exact log oracle, listener/process identity, release gate, and the remaining distinction between local TEST-NET-3 REJECT and untested gz02 PROXY.
